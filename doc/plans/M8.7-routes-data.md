# M8.7-routes-data · 路线库数据导入 + 轨迹封面生成实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** ① `protype/route_guides.csv` 35 条路线全量导入 routes 表（解析里程/爬升/难度/时长/清晰度/地形/安全提醒等结构化字段）；② 为每条路线**生成轨迹示意图封面 PNG**（确定性程序生成：地貌色底 + 蜿蜒轨迹线 + 起终点标记，无外部图片依赖）存 `backend/static/covers/`；③ 前端路线库/首页/详情接入封面（`/static/covers/{id}.png`，加载失败回退现有渐变模板）——路线库成为有真实数据+封面的可用状态。

**Architecture:** 导入走新种子脚本 `seed_routes_csv.py`（幂等：按 name upsert，与既有 6 条手工种子共存——CSV 含雨崩/虎跳峡同名线则**跳过**保留手工行避免数据漂移）。封面生成 `scripts/gen_covers.py`（读 routes → 按确定性种子生成 SVG → 无头 Chrome 批量转 PNG）。前端按 id 约定寻址封面，零迁移零新列。

**Tech Stack:** 无新依赖（Chrome 本机已有）。

**Files:**

- Create: `backend/tests/test_seed_routes_csv.py`

**导入映射（CSV → routes 列）：**
- name=路线名称（与手工种子同名跳过）；sport=运动类型（SPORT_MAP 同 seed_kb：徒步→hiking 等，默认 hiking）；region=所在地区
- distance_km=里程(km) 解析首个数字（"村内两日线往返约26.7km"→26.7）；climb_m=累计爬升(m) 首个数字；difficulty=难度(1-5) 首个数字取整 clamp 1-5；duration_h=建议用时 首个"Nh"数字；clarity=轨迹清晰度（高→high 中→mid 低→low，默认 mid）
- terrain=地形构成 原文存 JSON [{"type":原文,"pct":0}] 单项占位（无结构化比例）；warning=安全提醒 原文；elevation/pace 空 []；required_gear 空 []；status=published；source=csv

**封面生成（gen_covers.py）：**
- 每 route：seed=id → 城市沃斯特随机（python random.Random(id)）
- SVG 400x240：地貌渐变底（sport 色板 5 组）+ 山脊剪影两层 + **蜿蜒轨迹折线**（accent #A4F150 发光，8-14 个随机拐点 walk）+ 起点圆点/终点旗标 + 底部渐暗条 + 路线名（截 12 字）+ `Xkm ↑Ym ★N` 摘要行
- SVG 写 temp → Chrome headless --screenshot 批量（每张 ~1s，35 张）→ `backend/static/covers/{id}.png`
- 重复运行覆盖同名（确定性）

**前端接入：**
- routes.ts 导出 `coverUrl(id)`；列表卡封面区 `<Image src={coverUrl(r.id)} onError→标记失败回退渐变>`（页面级 failedCovers Set state）；首页 mini-card/hero、route-detail 顶图同款
- 渐变回退模板沿用现有 scene 方案

**验证：**
- `python -m app.seeds.seed_routes_csv` 幂等两跑（二跑 0 新增）；重复名跳过
- `python scripts/gen_covers.py` 生成 N 张 PNG（N=导入后 routes 总数）；抽 3 张尺寸/内容核验
- pytest 全绿（新增 seed 解析单测：里程/难度/清晰度解析边界）；前端四门禁
- uvicorn+dev:h5 截图：路线库列表（封面卡片）、首页热门（封面）、详情封面；筛选各维度（地区 chips 现在有 云南/山西/浙江/河南/江西/安徽 多地区）
