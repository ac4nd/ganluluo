# M7.5-onboard-weapp · 轻端第二波实现计划（引导三页 + weapp SSE 适配）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** ① 引导三页完整版（02 运动偏好 / 03 经验体能 / 04 装备清单多型号版）+ 新用户 onboarding 流接线；② `sse()` weapp 分支落地（`Taro.request enableChunked` + 分帧缓冲 + UTF-8 解码），补解析器单测。

**Architecture:** 引导流复用 PUT /profile（sports/exp_level/fitness）与 GET /gear/catalog + PUT /gear-list（GearItemIn 支持 model_id+custom_name，后端 UNIQUE(item_key,model_id) 允许同 item 多型号——完整版解锁多选）。weapp SSE：`Taro.request({enableChunked:true})` 返回 RequestTask，`onChunkReceived(ArrayBuffer)` → 手写 UTF-8 解码（小程序无 TextDecoder）→ **跨 chunk 行缓冲**（chunk 可能切断 `data:` 行）→ 复用现有事件解析。H5 fetch 实现保持不变。

**Tech Stack:** 无新依赖。
