**Interfaces:**
- `Provider.chat_stream(messages, tools) -> AsyncIterator[Delta]`（Protocol）；`FakeProvider.chat_stream` 改 async generator（calls 记录行为不变）
- `OpenAICompatProvider`：`httpx.AsyncClient(...).stream(...)` + `resp.aiter_lines()`；构造参数 `transport` 类型改 `httpx.AsyncBaseTransport | None`；`.model` 属性保留

- orchestrator 工具轮组装（OpenAI wire 合规）：
  - assistant 消息：`{"role": "assistant", "content": ..., "tool_calls": [{"id": <id 或合成>, "type": "function", "function": {"name": ..., "arguments": ...}}]}`
  - tool 消息：`{"role": "tool", "tool_call_id": <与 assistant 对应 id>, "content": ...}`（`name` 字段可保留）
  - id 合成规则：call 无 id 时 `call_{round}_{index}`（round 为当前工具轮次）
- orchestrator 主循环 `async for delta in provider.chat_stream(...)`
