# M3.5 · 配额管理（账号池 + VIP/试用分级）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 每用户按 quota_tier（trial/vip）执行每日对话次数与 token 配额，流式响应中超额返回 quota_exceeded 事件，流结束写 llm_usage 流水；/assistant/chat 加 per-user 限流。

**Architecture:** 单共享上游 LLM key（后端环境变量，永不下发）；配额检查在 run_chat 入口（DB 计数，无 Redis 依赖）；llm_usage 表做持久化流水 + 当日计数；sub_tokens 表建结构留 M5 开放平台。

**Tech Stack:** 无新依赖。

## Global Constraints

- 配额检查在用户消息持久化之前（超额时不落库不调 LLM）
- 官方 API key 只在后端环境变量，源码/示例/测试无可用凭据字面量

# tests/test_quota_service.py
import pytest

from app.models.quota import QuotaTier, LlmUsage
from app.models.user import User
from app.domains.admin.quota_service import get_status, record_usage

async def _make_user(session, email="q@b.com"):
    u = User(email=email, nickname="q", password_hash="x")
    session.add(u); await session.commit(); await session.refresh(u)
    return u

async def test_status_counts_and_limits(db):
    u = await _make_user(db)
    for _ in range(3):
        await record_usage(db, u.id, "s1", "m", 100, 50)
    st = await get_status(db, u.id, "trial")
    assert st.daily_chats_used == 3 and st.daily_chats_limit == 5
    assert st.daily_tokens_used == 450 and st.daily_tokens_limit == 20000
    assert st.allowed is True


async def test_status_over_limit(db):
    u = await _make_user(db, email="q2@b.com")
    for _ in range(6):
        await record_usage(db, u.id, "s2", "m", 5000, 1000)
    st = await get_status(db, u.id, "trial")
    assert st.allowed is False


async def test_tier_seed_idempotent(db):
    from app.domains.admin.quota_service import seed_tiers
    n1 = await seed_tiers(db); n2 = await seed_tiers(db)
    assert n1 >= 2 and n2 == 0
