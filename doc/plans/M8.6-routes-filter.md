# M8.6-routes-filter · 路线库筛选对齐「两步路」实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 路线库筛选升级为两步路式维度：**地区 / 时间 / 排序（标记数量）/ 运动类型**。后端 `GET /routes` 加 `created_after`（时间过滤）与 `sort`（排序）参数；前端 routes 页筛选区重构（运动 chips 保留 + 地区/时间/排序三组选择）。

**Architecture:** 时间过滤在 SQL（`created_at >= created_after`）；标记数量排序 python 侧（`len(track_points or [])` desc——MVP 数据量小，跨方言 JSON 长度函数不值得）。地区沿用现有 `region` 参数（ilike 匹配地区列+路线名），前端提供**从当前数据聚合的地区 chips**（不硬编码词表）。

**Tech Stack:** 无新依赖。
