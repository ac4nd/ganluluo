# M8.8-covers-minio · 封面图 MinIO 存储与 cover_url 字段实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 用户已在 `protype/covers/` 提供 1476 张真实路线封面 JPG（`NNNN_路线名.jpg`，476MB）且 CSV 扩充至 1470 行。启用 MinIO 存储：图片上传至 MinIO bucket（公共读），`routes` 表新增 `cover_url` 列存完整访问 URL；CSV 新数据同步导入；前端封面优先用 `cover_url`。

**Architecture:** 上传脚本按**路线名**匹配（covers 文件名 `NNNN_名称.jpg` 去序号后与 CSV/routes 的 name 模糊匹配）→ `MinioMediaStore.put_object`（media 域抽象复用）→ `set_bucket_policy` 开 covers/ 前缀匿名读 → `cover_url = http://{endpoint}/{bucket}/{key}` 存库。前端 `cover_url` 优先（非空用 MinIO URL），空回退渐变占位。

**Tech Stack:** 无新依赖（minio SDK 已有）。
